A [make.fun](https://make.fun) bounty entry: a small Node program that writes one
line of at most 200 characters about a small good thing that happened today to
`/output/entry.txt`.

The line:

> This morning the stray cat that always ignores me trotted over, headbutted my ankle, and escorted me to the warung like a tiny bodyguard on duty.

## Run it

```sh
node main.ts
```

It writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
Deterministic, stdlib only, no network — the same text on every run.
